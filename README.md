# Gerenciador de Tarefas
## Um simples gerenciador de tarefas feito na linguagem *Java*, utilizando os princípios do Encapsulamento. 

### 🛠️ To-do List
- [ ] Persistência de Tarefas;
- [ ] Interface Gráfica;

### ⚙️ Funcionalidades: 
É possível adicionar tarefas básicas, dando a elas um título, descrição e uma data de conclusão. Utilizando o menu inicial, também é possível listar e modificar seu status.

### 💻 Tecnologias: 
Foi utilizado a linguagem Java, focando no uso do Encapsulamento dos atributos e métodos assessores (Getters e Setters) e construtor, manipulação de ArrayList, bem como códigos condicionais. Também foi utilizado o git para o versionamento.

### Como Executar:
> Requerimentos: Java 8.0+

### Via IDE:
1. Clone o repositório ou baixe o [código fonte](https://github.com/wellingtonmtm/Gerenciador-de-Tarefas/tree/main/src/gerenciadordetarefas)
2. Crie um projeto vazio na sua IDE, desmarque a classe principal.
3. Arraste ou copie os arquivos .java para dentro do projeto, inicie e selecione o arquivo `GerenciadorDeTarefas.java` como classe Principal.

### Via Terminal:
1. Abra o terminal e navegue até a pasta onde os arquivos `.java` estão salvos.
2. Compile o código com o comando: `javac GerenciadorDeTarefas.java Tarefa.java`
3. Execute o programa com o comando: `java GerenciadorDeTarefas`
