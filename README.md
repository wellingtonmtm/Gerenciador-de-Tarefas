# Gerenciador de Tarefas
## Um simples gerenciador de tarefas feito na linguagem *Java*, utilizando os princípios do Encapsulamento.

### ⚙️ Funcionalidades: 
É possível adicionar tarefas básicas, dando a elas um título, descrição e uma data de conclusão. Através do botões, é possível modificar o status ou deletar a tarefa selecionada.

### 💻 Tecnologias: 
Foi utilizado a linguagem Java, focando no uso do Encapsulamento dos atributos e métodos assessores (Getters e Setters) e construtor, manipulação de ArrayList, bem como códigos condicionais. Também foi utilizado o git para o versionamento e Swing para GUI.

### Como Executar:
> Requerimentos: Java 8.0+

### Via IDE:
1. Clone o repositório ou baixe o [código fonte](https://github.com/wellingtonmtm/Gerenciador-de-Tarefas/tree/main/src/gerenciadordetarefas)
2. Crie um projeto vazio na sua IDE.
3. Arraste ou copie os arquivos .java para dentro do projeto, inicie e selecione o arquivo `GerenciadorDeTarefas.java` como classe Principal.

### Via Terminal:
1. Abra o terminal e navegue até a pasta src.
2. Compile o código com o comando: `javac gerenciadordetarefas/GerenciadorDeTarefas.java`
3. Execute o programa com o comando: `java gerenciadordetarefas.GerenciadorDeTarefas`
